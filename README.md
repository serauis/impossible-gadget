A catalogue photograph of an impossible gadget, entered in make.fun's
["The Catalogue Photo of an Impossible Gadget"](https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341)
bounty. The product is the **Square Bubble Wand**: a polished chrome wand with a
square frame, shot mid-use on a seamless studio backdrop as the perfect
cube-shaped soap bubbles it blows drift around it, rainbow films and all.
A studio product photograph of a product physics will not allow.

## Run it

```bash
python3 main.py
```

`main.py` writes the finished 1024x1024 PNG to `/output/entry.png`,
byte-for-byte identical on every run, with no network access.
